Sinkronisasi GitHub (supaya perubahan tersimpan di semua device)

Semua device akan otomatis membaca data terbaru dari repo superlink-mantap/highlightkinerja. Supaya perubahan admin (password, tampilan, menu) ikut tersimpan ke repo itu, tempel token GitHub di bawah ini. Token hanya disimpan di penyimpanan lokal device ini, tidak dikirim kemana-mana selain ke GitHub — sekali disimpan, tidak perlu dimasukkan ulang di device yang sama.
